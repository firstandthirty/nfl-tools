# Processed PFF Data Dictionary

The processed layer is generated by `scripts/build_processed_week.py` from cached raw PFF API responses. It intentionally contains stable tables and deterministic derived fields only; it does not create rankings, labels, tweet copy, or interestingness scores.

## Common Fields

- `season`: NFL season requested.
- `week`: NFL week requested.
- `game_id`: PFF game identifier when available or mapped from `games.csv`.
- `player_id`: PFF player identifier when available.
- `player_name`: normalized from PFF `player`.
- `team`: PFF team abbreviation.
- `opponent`: mapped from `games.csv` for single-team weekly rows.
- `position`: PFF position.
- `draft_season`: PFF draft season.
- `rookie`: `draft_season == season`.

## Tables

- `games.csv`: Week schedule and team/opponent mapping from `/v1/games`.
- `passing.csv`: QB passing summary from `/v1/facet/passing/summary`.
- `receiving.csv`: Receiver usage/production from `/v1/facet/receiving/summary`.
- `rushing.csv`: Rusher usage/production from `/v1/facet/rushing/summary`.
- `pass_blocking.csv`: Player pass-blocking from `/v1/facet/offense/pass_blocking`.
- `pass_rush.csv`: Player pass-rush from `/v1/facet/defense/pass_rush`.
- `run_defense.csv`: Player run-defense from `/v1/facet/defense/run`.
- `coverage.csv`: Player coverage from `/v1/facet/defense/coverage`.
- `coverage_scheme.csv`: Player man/zone coverage splits from `/v1/facet/defense/coverage_scheme`.
- `time_in_pocket.csv`: QB time-in-pocket splits from `/v1/facet/signature/passing/time_in_pocket`.

## Derived Fields

- `yards_after_contact_per_attempt`: `yards_after_contact / attempts` when `attempts > 0`.
- `targets_per_route_run`: `targets / routes` when `routes > 0`.
- `pressure_rate_allowed`: `pressures_allowed / pass_block_snaps` when `pass_block_snaps > 0`.
- `pressure_rate`: `total_pressures / pass_rush_snaps` when `pass_rush_snaps > 0`.
- `run_stop_rate`: `stops / run_defense_snaps` when `run_defense_snaps > 0`.
- `forced_incompletion_rate_derived`: `forced_incompletes / targets` when `targets > 0`.

Missing denominators leave the derived field missing.
